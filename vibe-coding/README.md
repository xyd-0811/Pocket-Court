# 随身异议 · 法庭开庭

采用已确认的 A 方案：米金法庭、深蓝对话框、木色栏杆和酒红按钮。手机使用紧凑舞台、两列台词和固定底部操作区；电脑使用左右双栏。仓库根入口与本目录入口均已接入新页面，原始语音素材位于上级 `img/` 和 `sound/`。

## 启动

直接打开仓库根目录 `index.html` 即可试听，或从仓库根目录启动静态服务器：

```powershell
py -m http.server 8000
```

浏览器访问 `http://localhost:8000/` 或 `/vibe-coding/`。手机请使用部署后的 HTTPS 地址；localhost 指访问设备自身。真实动作感应需要设备、浏览器支持和授权；可点击「模拟挥动」检查发声流程。

## 已实现

- 14 位角色搜索、律师/检察官分组，20 种台词、81 段语音按角色及语言筛选。
- 灵敏度 0.2–80、峰值归零、真实动作触发、模拟挥动、震动开关。
- 舞台区域内的鼠标触发和 `Ctrl+Shift+Z` 快捷键，沉浸模式可双击舞台或按 Esc 退出。
- 角色、台词、语言和操作偏好保存在浏览器；网络语音首次播放后缓存，可清除缓存和试听记录。
- 从手机或电脑选择一首或多首音乐，支持播放、暂停、切歌、进度、音量和循环；可在异议触发时自动播放。
- 本地歌单支持清空，不会删除设备文件。
- 更新 PWA manifest，角色弹窗支持键盘焦点与 Esc 关闭。

这是静态前端。背景音乐直接读取设备文件，刷新后需重新选择。成步堂为概念立绘，其余角色使用姓名档案卡。

`catalog.js` 保存角色与语音目录，`app.js` 处理交互，`styles.css` 保存响应式样式。目录中的 `prototype-*.html` 仅为设计参考，正式入口不加载它们。

修改前页面位于工作区 `outputs/before-courtroom-design/`。`work/package-courtroom.cjs` 可生成发布目录及内嵌图片/语音的单文件离线版。原作来源与 MIT 许可已保留。
