# 随身异议 · 法庭开庭

基于 Shoyu 的 Portable-objection 重制，采用已确认的法庭风格。手机紧凑布局，电脑左右双栏；保留 14 位角色、20 种台词、81 段语音。

双击 index.html 可试听。也可在仓库根目录运行 py -m http.server 8000 后访问 http://localhost:8000/。手机动作触发请使用部署后的 HTTPS 地址。

角色搜索、语言筛选、语音缓存、灵敏度设置、震动开关、模拟挥动、沉浸模式和本地背景音乐均已接入。成步堂为概念立绘，其余人物使用姓名档案卡。

详细说明见 [vibe-coding/README.md](vibe-coding/README.md)。
